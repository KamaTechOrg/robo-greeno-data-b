Sprint 1 Kickoff — Meeting Agenda
  
  1. Orientation (5 min)
  Checkin on the project goal and the end-to-end-first strategy. Design doc?

  2. Project board walkthrough (10 min)
  Walk through the GitHub project board. Cover the Sprint 1 issues, what each one means, and how we'll use the board day-to-day — moving cards, what "done" actually means.


  3. Sprint planning — pull cards into active work (20 min)
  Go through the Sprint 1 backlog together. Assign owners to each sprint commit. Anyone who wants to own something should claim it now; orphaned cards get assigned before we
  leave. Usually there will be backlog cards we won't do in the current sprint, but we're still getting everything set up so we should plan to do everything there this sprint, or talk about why not. What are we missing?

  4. Open questions (30 min)
  Surface blockers, unknowns, and anything the plan left unclear. Likely candidates:
  - AgCloud access — do we have it? Who's leading the orientation memo?
  - Hardware status — what Pi model, what accelerator?
  - Webcam / camera availability for frame_quality.py testing
  - Licensing gut-check — does anyone have a strong prior on AGPL vs. permissive?

  5. Next touchpoint
  Confirm next standup / check-in time before closing.
